# پروژه مدیریت کاربران با FastAPI و MongoDB

این پروژه یک برنامه تحت وب برای مدیریت اطلاعات کاربران است که با استفاده از **FastAPI**، پایگاه داده **MongoDB** و قالب‌های **Jinja2** ساخته شده است. مدیر پس از ورود می‌تواند فهرست کاربران را مشاهده کند و عملیات افزودن، ویرایش و حذف کاربران را انجام دهد.

## امکانات پروژه

- ورود مدیر و خروج از حساب کاربری
- محافظت از صفحات مدیریت با احراز هویت
- افزودن کاربر جدید
- ویرایش اطلاعات کاربران
- حذف کاربران
- نمایش فهرست کاربران
- جست‌وجوی کاربران بر اساس نام، شماره موبایل یا ایمیل
- اعتبارسنجی اطلاعات ورودی با Pydantic
- نمایش خطاهای اعتبارسنجی به زبان فارسی
- ذخیره اطلاعات در MongoDB
- محافظت از فرم‌های تغییردهنده اطلاعات با توکن CSRF
- استفاده از فایل CSS برای طراحی صفحات
- اجرای برنامه با Uvicorn

## فناوری‌های استفاده‌شده

- Python
- FastAPI
- MongoDB
- PyMongo
- Pydantic
- Jinja2
- HTML و CSS
- SessionMiddleware
- Uvicorn
- Docker و Docker Compose (برای اجرای کانتینری، در صورت نیاز)

### توضیحات فایل‌ها

- `main.py`: نقطه ورود برنامه و تنظیمات اصلی FastAPI.
- `auth.py`: مدیریت ورود مدیر، خروج و احراز هویت.
- `students.py`: مسیرهای نمایش، افزودن، ویرایش، جست‌وجو و حذف کاربران.
- `schemas.py`: مدل‌ها و اعتبارسنجی اطلاعات ورودی.
- `database.py`: تنظیم اتصال به MongoDB و دسترسی به پایگاه داده.
- `security.py`: ابزارهای مرتبط با امنیت و هش رمز عبور.
- `create_admin.py`: ابزار ایجاد حساب مدیر.
- `change_admin_password.py`: ابزار تغییر رمز عبور مدیر.
- `migrate_students.py`: ابزار انتقال اطلاعات کاربران، در صورت نیاز.
- `requirements.txt`: وابستگی‌های Python پروژه.
- `Dockerfile`: دستورالعمل ساخت تصویر Docker.
- `compose.yaml`: تنظیم سرویس‌های موردنیاز برای اجرای کانتینری.
- `.dockerignore`: مشخص‌کردن فایل‌هایی که نباید وارد تصویر Docker شوند.
- `.gitignore`: مشخص‌کردن فایل‌هایی که نباید در Git ثبت شوند.
- `templates/`: قالب‌های HTML صفحات برنامه.
- `static/style.css`: استایل صفحات وب.

## نصب و راه‌اندازی

### ۱. ورود به پوشه پروژه

```bash
cd ~/Desktop/fastapi
```

### ۲. فعال‌کردن محیط مجازی

اگر محیط مجازی قبلاً ساخته شده است:

```bash
source .venv/bin/activate
```

اگر محیط مجازی وجود ندارد، ابتدا آن را ایجاد کنید:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### ۳. نصب وابستگی‌ها

```bash
python -m pip install -r requirements.txt
```

### ۴. تنظیم اتصال به MongoDB

مطمئن شوید سرویس MongoDB فعال است و برنامه می‌تواند به آن متصل شود.

پایگاه داده مورد استفاده پروژه:

```text
fastapi_db
```

مجموعه کاربران:

```text
students
```

اگر آدرس اتصال یا نام پایگاه داده در تنظیمات محیطی پروژه تعریف شده است، مقادیر مناسب را مطابق تنظیمات فعلی پروژه وارد کنید. اطلاعات حساس مانند رمز عبور پایگاه داده را در کد یا مخزن Git قرار ندهید.

### ۵. تنظیم حساب مدیر

اگر هنوز حساب مدیر ایجاد نشده است، ابزار مربوط به ایجاد مدیر را بررسی و اجرا کنید:

```bash
python create_admin.py
```

برای تغییر رمز عبور مدیر نیز از ابزار زیر استفاده کنید:

```bash
python change_admin_password.py
```

این ابزارها را مطابق ورودی‌ها و دستورالعمل‌های پیاده‌سازی‌شده در پروژه اجرا کنید. رمز عبور را در مخزن Git یا فایل‌های عمومی قرار ندهید.

### ۶. اجرای برنامه

```bash
python -m uvicorn main:app --reload
```

پس از اجرای موفق برنامه، صفحه ورود مدیر را باز کنید:

http://127.0.0.1:8000/login

## نحوه استفاده

۱. صفحه ورود را باز کنید.

۲. با اطلاعات حساب مدیر وارد شوید.

۳. فهرست کاربران را در صفحه اصلی مشاهده کنید.

۴. برای افزودن کاربر، گزینه افزودن کاربر جدید را انتخاب کنید.

۵. برای ویرایش، گزینه مربوط به کاربر موردنظر را انتخاب کنید.

۶. برای حذف، از گزینه حذف کاربر استفاده کنید.

۷. برای پیدا کردن کاربران، از کادر جست‌وجو استفاده کنید.

۸. پس از پایان کار، از حساب مدیر خارج شوید.

## مسیرهای اصلی برنامه

| متد | مسیر | کاربرد |
|---|---|---|
| `GET` | `/login` | نمایش فرم ورود مدیر |
| `POST` | `/login` | بررسی اطلاعات ورود |
| `POST` | `/logout` | خروج مدیر |
| `GET` | `/` | نمایش فهرست کاربران |
| `GET` | `/add` | نمایش فرم افزودن کاربر |
| `GET` | `/add/{student_id}` | نمایش فرم ویرایش کاربر |
| `POST` | `/add` | افزودن کاربر یا ذخیره تغییرات |
| `POST` | `/students/{student_id}/delete` | حذف کاربر |

مسیرهای مدیریت کاربران به احراز هویت مدیر نیاز دارند. درخواست‌های تغییر اطلاعات نیز باید الزامات امنیتی برنامه، از جمله توکن CSRF، را رعایت کنند.

## اطلاعات کاربران

مدل کاربران می‌تواند شامل فیلدهای زیر باشد:

- نام
- سن
- تاریخ تولد
- نام پدر
- محل تولد
- شماره موبایل
- ایمیل
- آدرس

اعتبارسنجی اطلاعات ورودی بر اساس مدل تعریف‌شده در `schemas.py` انجام می‌شود. برای اطلاع از محدودیت‌های دقیق هر فیلد، به همان فایل مراجعه کنید.

## مستندات FastAPI

در صورت فعال‌بودن مستندات خودکار در تنظیمات برنامه، می‌توانید از آدرس زیر استفاده کنید:

http://127.0.0.1:8000/docs

## اجرای پروژه با Docker

فایل‌های `Dockerfile` و `compose.yaml` برای اجرای کانتینری پروژه در نظر گرفته شده‌اند.

پیش از اجرای Docker Compose، تنظیمات سرویس برنامه، اتصال به MongoDB، متغیرهای محیطی و فایل‌های موردنیاز را بررسی کنید. برای اجرای برنامه با Docker، از دستورالعمل‌های متناسب با تنظیمات فعلی `compose.yaml` استفاده کنید.

## نکات امنیتی

- رمز عبور مدیر باید به‌صورت امن و با استفاده از هش نگهداری شود.
- کلید محرمانه نشست باید از طریق متغیر محیطی تنظیم شود.
- فایل `.env` و سایر اطلاعات حساس را در Git ثبت نکنید.
- از رمزهای عبور قوی استفاده کنید.
- برای فرم‌های تغییردهنده اطلاعات، توکن CSRF را غیرفعال نکنید.
- در محیط عملیاتی، حالت توسعه `--reload` را فعال نگذارید.
- پیش از تغییرات مهم، از پایگاه داده MongoDB نسخه پشتیبان تهیه کنید.
- فایل‌های پشتیبان را تا زمانی که از صحت نسخه جدید مطمئن نشده‌اید حذف نکنید.
